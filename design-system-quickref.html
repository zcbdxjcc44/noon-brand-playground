Themes

Void — dark (default)
Depth via brighter borders
Paper — light
Depth via real drop shadows
Design both. The depth models differ, so a Void layout can break in Paper. Reference semantic bg/fg roles so themes flip correctly.

Spacing scale — 4px base grid (sp)

Stay on the scale: 0·5=2, 1=4, 2=8, 3=12, 4=16, 5=20, 6=24, 7=32, 8=40, 9=48, 10=64, 11=80, 12=96. Need a new size? Add a step to the scale, don't use a one-off value.

Red flags — you've left the system if…

✕ A hex or px value that isn't in the token scale
✕ Purple used for anything but the voice tutor
✕ A layout that only works in one theme
✕ A Latin-only design with no Arabic / RTL consideration
